# Win-CodexBar + Mobile Connect v0.72.1

## Windows の設定

- 「プロバイダー」見出し横のボタンで、有効なプロバイダーだけに絞り込めます。
- Discord Rich Presence を専用タブで設定できます。表示する項目と形式を選び、Discord が受理した内容をプレビューできます。「使用量を優先」は、取得できたトークン数をステータスに表示します。
- Discord デスクトップ版への接続状態を表示します。接続の再試行を短くし、集計が完了したら次の定期更新を待たずに反映します。Discord への共有は設定から有効にできます。

## 使用量・コスト

- Codex の表示期間を切り替えても、モデルが特定できた使用量の価格情報を保持します。週次クォータ履歴は、近接したリセット時刻の観測をまとめ、7日間の境界を維持します。
- 概要を開いたまま集計が更新されます。日次チャートではトークンがあり、料金を算出できなかった日を破線で表示します。
- GPT-6 Luna の公開 API 単価を使ったコスト推定に対応しました。
- Codex のアカウント累計トークンと、このPCの履歴から集計したトークンや推定コストを個別に表示します。
- Mobile Connect は送信元PCの集計更新をバックグラウンドで反映します。既存の接続コードで利用できます。

## ブラウザの自動取得

- Grok と Muse AI は、ブラウザのセッションが拒否された場合に別の候補を確認します。Manus、Grok、Muse AI の自動取得では、手動モード用に保存した古い Cookie を優先しません。
- Vivaldi などが Cookie データベースをロックしており、利用可能な候補を取得できない場合は、Manus、Grok、Muse AI、Muse Code でブラウザ名と対処方法を表示します。自動取得を再試行する場合は、ブラウザを完全に終了してから更新してください。
- すでに取り込んだ Cookie を使う場合は、対象のプロバイダーの Cookie ソースで「手動」を選択します。
- Muse Code の Web チーム枠には、既存の Muse Code ログインと同じアカウントのブラウザセッションが必要です。

## 更新方法

Windows 用ポータブル EXE をダウンロードし、アプリを終了して現在の EXE を置き換えます。既存の設定フォルダを使うため、接続コードやプロバイダーの設定を引き継げます。Windows 10 以降の x64 と WebView2 Runtime が必要です。EXE は未署名で、このリリースの `SHA256SUMS` と `build-provenance.json` で照合できます。
